# done yet? – MVP

### Main problem

In many households, one person carries most of the "mental load" of managing the home. They need to remember what needs to be done, decide when it should be done, assign tasks to their partner, and often remind them about unfinished chores.

The problem is not only doing household chores — it is having to constantly remember, plan, coordinate and remind others about them.

done yet? aims to take over this coordination and reminder role, so household responsibilities can be shared without one partner becoming the "manager" of the home.

### Smallest set of functionality

* User registration and login
* Creating a household and inviting a partner
* Creating, editing, completing and deleting household tasks
* Assigning tasks to a specific household member
* Setting due dates and recurring tasks
* Displaying a simple "Today's tasks" dashboard
* Sending task reminders through a Telegram bot
* Allowing users to mark a task as completed directly from Telegram
* AI-assisted generation of household tasks based on household characteristics (e.g. children, pets, house/apartment)
* Basic task categories such as cleaning, shopping, laundry, maintenance and bills

### What is NOT included in the MVP

* Mobile applications
* Advanced analytics and statistics
* Gamification, points or leaderboards
* Google Calendar integration
* WhatsApp integration
* Complex AI agents or autonomous task management
* Advanced notification channels such as SMS or push notifications
* Automatic analysis of relationship dynamics or "mental load scores"
* Sharing households with multiple families
* Advanced permission and role management

### Success criteria

* A user can create an account and set up a household with a partner.
* Users can create and assign household tasks without needing to communicate them manually to each other.
* At least 80% of created tasks can be completed through the normal application flow or directly through Telegram.
* Telegram reminders are delivered for tasks with a configured reminder time.
* A user can mark a task as completed from Telegram and the change is immediately reflected in the web application.
* At least 70% of AI-generated household tasks are accepted or saved by the user.
* A new user can configure a basic household and create their first task in less than 5 minutes.
