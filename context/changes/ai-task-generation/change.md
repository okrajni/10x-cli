# AI Task Generation

**Change ID:** ai-task-generation  
**Status:** implementing  
**Created:** 2026-09-02  
**Updated:** 2026-09-02

## Summary

Add AI-powered task generation to help users externalize household responsibility management. After registration, users describe their household and receive AI-suggested recurring tasks. On the dashboard, a button allows on-demand task suggestions.

## Context

Users experience mental load from constantly thinking about household responsibilities. This feature offloads task ideation to AI, suggesting relevant tasks based on household context.
